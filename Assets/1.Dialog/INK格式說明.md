# ink 劇本格式說明

古神咖啡廳｜對話系統劇本撰寫規範
最後更新：2026-08-26

## 支援狀況

| 功能 | 狀況 |
|---|---|
| 一行一句、逐字顯示、點擊下一句 | ✅ |
| knot 分段與跳轉 | ✅ |
| 變數、條件、內插 | ✅ |
| 指令 `@fade` `@bg` `@fx` `@clear` `@sprite` `@dizzy`、tag `#speaker` | ✅ |
| 其他指令（`@se` `@bgm` `@wait`…） | ⚠️ 不會壞，只印警告，沒有效果 |
| 選項（`*` `+`） | ❌ 寫了會卡住 |
| EXTERNAL 函式 | ❌ 執行時報錯 |

## 1. 檔案

```
Assets/Dialog/
├─ prologue.ink     ← 寫這個
└─ prologue.json    ← Unity 自動編譯，不要手改
```

- `.ink` 存檔後切回 Unity 會自動編譯出同名 `.json`
- `DialogSystem` 的 `Ink Asset` 欄位要拖 **`.json`**
- 多檔時用 `INCLUDE 檔名.ink` 從主檔串起來，只編譯主檔

## 2. 基本寫法

```ink
// 註解不會進遊戲

->prologue_dream        // 入口

==prologue_dream==      // 段落（knot）
睜開眼
熟悉的房間
->prologue_wake         // 跳到下一段

==prologue_wake==
鬧鐘響了
->END                   // 整篇結束
```

- **一行 = 一句 = 一次點擊**，空行不產生內容
- `==名稱==` 定義段落，`->名稱` 跳過去
- 註解：`//` 或 `/* */`

### knot 命名

> ⚠️ **只能用英數與底線，不能有空格或中文**（中文會編譯失敗）。檔名可以用中文，knot 不行。

格式 `檔名_英文用途`：`ch01_open`、`prologue_dream`。同檔內不可重複。

## 3. 角色名

用 `#speaker:` 指定，名字會顯示在獨立的名字欄，**不要打在文字裡**。

```ink
#speaker:yuan
今天也沒什麼客人。
#speaker:ling
妳從剛剛就一直趴在那裡。

#speaker:
門口的風鈴響了。          ← 冒號後留空 = 旁白，名字欄隱藏
```

⚠️ **說話者會一直沿用到下一個 `#speaker:` 為止。** 同一個人連講三句只要寫一次；**換成旁白一定要寫 `#speaker:`**，不然會掛著上一個人的名字。

角色 key 一覽（資料表裡對應到中文名，完整規則見第 5 節）：

| key | 顯示 |
|---|---|
| `momoka` | 桃花（女A） |
| `saki` | 紗季（女B） |

（淵與苓的 key 還沒確定）

身分還沒表明時用 `as:` 覆蓋顯示：

```ink
#speaker:ling as:？？？
歡迎光臨。
```

## 4. 演出指示

演出指示分兩套：`@` 指令行與 `#` tag。

### 4-0. `@` 和 `#` 的差別

**一句話：`@` 是「在這裡做一件事」，`#` 是「描述下面那句話」。**

| | `@` 指令行 | `#` tag |
|---|---|---|
| 寫在哪 | **自己單獨一行** | 它要修飾的那句文字**上方** |
| 執行時機 | 就在**寫的那個位置**，由上往下 | 跟**下一句文字同時**發生 |
| 需要文字嗎 | 不用，自己就是一行 | **一定要有下一句文字**，否則整個不執行 |
| 放段落結尾 | ✅ 可以 | ❌ 不會執行（後面沒文字可綁） |
| 會不會顯示 | 不會，也不用點擊，執行完自動往下 | 不會 |
| 打錯字 | 被當成台詞顯示在對話框（一眼看到） | 靜靜地不生效 |
| 管什麼 | 畫面／聲音**發生什麼事** | 這句話**誰說的、怎麼呈現** |
| 目前有 | `@bg` `@fade` `@fx` `@clear` `@sprite` `@dizzy` | `#speaker` |

```ink
@bg:cafe_night          ← 事件：現在換背景
@fade:in                ← 事件：現在淡入

#speaker:yuan           ← 屬性：下面這句是淵說的
今天也沒什麼客人。        ← ↑ 兩種寫法都作用在這句
```

**判斷口訣：這件事需不需要一句台詞才成立？**
需要 → `#`（誰說的、用什麼語氣、配什麼語音）
不需要 → `@`（換背景、淡入淡出、播音效、清畫面）

寫錯邊會印警告告訴你該改用哪個，但仍然會執行，不會擋住測試。
不認得的指令也只印警告——可以先寫，等程式做好就自動生效。

### 4-0-1. 共通的寫法規則

```
@指令:值 選項:值 旗標
#指令:值 選項:值 旗標
```

| 部位 | 說明 |
|---|---|
| **指令** | 冒號前那段，例 `bg`、`fade`。不分大小寫 |
| **值** | 冒號後那段，是這個指令的主參數（背景 key、要顯示的文字…）。可以省略 |
| **選項** | 用空白隔開的 `名稱:值`，順序不拘，例 `dur:2` `in:fade` |
| **旗標** | 沒有冒號的選項，寫了就代表開啟，例 `nowait` |
| **引號** | 值裡有空白時用 `"` 包起來：`@fx:"滴滴 滴滴" anim:rise` |

⚠️ 一行只能寫一個指令。要做兩件事就寫兩行。

### 4-0-2. 等待機制

大部分會動的指令**預設會等它跑完**才繼續下一行——因為轉場通常要跑完才接下一句。

加 `nowait` 就不等，讓它在背景跑，下一行立刻接上。想讓兩個效果同時發生就靠這個：

```ink
@fade:out nowait        ← 一邊淡黑
@fx:碰 anim:pop         ← 一邊跳出特效字，兩件事同時進行
```

### 4-1. `@` 指令一覽

| 指令 | 一句話 | 會等嗎 |
|---|---|---|
| `@bg` | 換背景 | `in:fade` 時會等 |
| `@fade` | 全螢幕淡入淡出 | 會 |
| `@fx` | 特效字（擬聲字） | 會 |
| `@sprite` | 立繪出現／換表情／換位置／退場 | 淡入淡出時會等 |
| `@clear` | 清空對話框 | 不會（瞬間完成） |
| `@dizzy` | 暈眩：畫面扭曲＋色散＋壓黑 | `pulse` 會等，`on`／`off` 不會 |

---

#### `@bg` 換背景

```ink
@bg:saki_room_dark              直接切換（瞬間）
@bg:cafe_night in:fade          淡出換圖再淡入
@bg:cafe_night in:fade dur:2    整段 2 秒（淡出 1 秒＋淡入 1 秒）
@bg:cafe_night in:fade nowait   不等它跑完，下一行馬上接
```

| 參數 | 可填 | 預設 | 說明 |
|---|---|---|---|
| **值** | 背景 key | 必填 | 要換成哪張圖。key 登記在 `Assets/SO/DialogDatabase.asset` |
| `in:` | `cut` / `fade` | `cut` | `cut` 瞬間換；`fade` 是**淡出→換圖→淡入**（不是交叉溶接） |
| `dur:` | 秒數 | `0.5` | **整段**的總時間，前後各佔一半。`in:cut` 時無效 |
| `nowait` | 旗標 | 不加＝會等 | 加了就不等淡入淡出跑完 |

- 找不到 key 會印警告並**維持原本的背景**，不會變黑
- `in:cut` 是瞬間完成的，所以 `nowait` 對它沒有意義

#### `@fade` 全螢幕淡入淡出

在整個畫面最上層蓋一張色塊，用來做轉場。

```ink
@fade:out               淡出（畫面被蓋住，預設變黑）
@fade:in                淡入（色塊消失，畫面恢復）
@fade:out dur:2         2 秒慢慢黑
@fade:out color:white   淡成白色
@fade:in nowait         不等它跑完
```

| 參數 | 可填 | 預設 | 說明 |
|---|---|---|---|
| **值** | `out` / `in` | 必填 | `out` 蓋起來、`in` 恢復。填別的會印警告並跳過 |
| `dur:` | 秒數 | `0.5` | 淡入淡出的時間。`0` 就是瞬間 |
| `color:` | `black` `white` `red` `#RRGGBB` | `black` | 蓋幕的顏色。只有 `out` 需要指定 |
| `nowait` | 旗標 | 不加＝會等 | 加了就在背景淡，下一行立刻接 |

⚠️ **黑幕會蓋住對話框和背景，但蓋不住特效字。**
⚠️ **`@fade:out` 之後一定要有 `@fade:in`**，否則畫面會一直黑著，看起來像當機——這是最常見的失誤。

#### `@fx` 特效字（擬聲字）

「滴滴滴滴」由大變小往上飛那類演出。**文字寫在指令裡**，不佔用對話框、不需要點擊。

```ink
@fx:滴滴滴滴 anim:rise         用 rise 這組動畫
@fx:滴滴滴滴                   anim 省略 = 用資料表第一筆
@fx:滴滴滴滴 anim:rise dur:2   蓋掉預設的秒數
@fx:碰 anim:pop nowait         不等它播完，下一行馬上接
@fx:"滴滴 滴滴" anim:rise       文字含空白時用雙引號
```

| 參數 | 可填 | 預設 | 說明 |
|---|---|---|---|
| **值** | 要顯示的文字 | 必填 | 直接寫中文。含空白要用 `"` 包起來 |
| `anim:` | 預設名稱 | 資料表第一筆 | `FxTextDatabase` 裡登記的動畫，例 `rise` |
| `dur:` | 秒數 | 預設裡設定的值 | **每個字**的動畫長度，不是整串的總長 |
| `nowait` | 旗標 | 不加＝會等 | 連續丟好幾組特效字時要加，否則會一組一組排隊 |

**預設是一個字一個字分開飛**：`滴滴滴滴` 會生成 4 個獨立文字，依序延遲送出、各自跑自己的縮放與飛行。要整串一起飛就在預設裡把「一個字一個字」取消勾選。

動畫參數都在 `FxTextDatabase` 資產裡調（Play 模式下每筆旁邊有 `▶ 預覽` 可以直接看）：

| 資產欄位 | 作用 |
|---|---|
| 每個字的動畫長度 | 單一個字從出現到消失的秒數 |
| 時間曲線 | 快慢節奏，中間拉高＝先衝後慢 |
| 淡入／淡出 | 頭尾各自的透明度過渡秒數 |
| 起始／結束字級 | 由大變小就是 120 → 40 |
| 顏色 | 特效字的顏色 |
| 起點 | 相對 FX 容器中心，(0,0) 是畫面正中央 |
| 飛行位移 | 往哪飛，y 正值＝往上 |
| 每個字的間隔 | 逐字送出的延遲，做出節奏感 |
| 每個字排開的方向 | (60,0) 往右排成一列；(0,0) 全疊同一點 |
| 每個字的隨機偏移 | 想散亂一點就調大 |

**要新效果就加一筆預設**（`pop`、`shake`、`drop`…），劇本寫 `anim:新名字` 即可，不用改程式。

特效字畫在黑幕**之上**，所以黑畫面裡也看得見——鬧鐘那種演出就是靠這個。

#### `@sprite` 立繪

```ink
@sprite:momoka at:left              桃花站左邊（表情用 normal）
@sprite:momoka face:smile at:left   指定表情
@sprite:momoka face:sad             只換表情，位置不動
@sprite:momoka at:right             只換位置，表情不動
@sprite:momoka out                  退場
@sprite:* out                       全部退場
@sprite:saki at:right in:cut        不要淡入，直接出現
```

| 參數 | 可填 | 預設 | 說明 |
|---|---|---|---|
| **值** | 角色 key 或 `*` | 必填 | `*` 只能配 `out` 使用 |
| `face:` | 表情 | `normal` | 實際查表用的是 `角色_表情`，例 `momoka_smile` |
| `at:` | 位置名稱 | 第一次出現＝第一個錨點<br>之後＝維持原位 | `left` `center` `right`，名稱由 Unity 端的錨點決定 |
| `in:` | `fade` / `cut` | `fade` | 第一次出現時的進場方式 |
| `out` | 旗標或 `out:cut` | — | 寫了就是退場 |
| `dur:` | 秒數 | `0.3` | 淡入淡出時間 |
| `nowait` | 旗標 | 不加＝會等 | 加了就不等淡入淡出 |

**一個角色同時只會有一份立繪**，重複 `@sprite:momoka` 是換表情或換位置，不會疊出第二個。

##### 說話者強調（自動）

`#speaker:` 一改，立繪會自動跟著變：

| 狀態 | 表現 |
|---|---|
| 正在說話的人 | 原本的大小與亮度 |
| 其他人 | **縮小並壓暗** |
| 旁白（`#speaker:`） | 預設維持原狀（可在 Unity 端改成全部壓暗） |

```ink
@sprite:momoka at:left
@sprite:saki at:right

#speaker:momoka
妳今天太安靜了。            ← 桃花亮，紗季暗

#speaker:saki
……有嗎。                  ← 換紗季亮，桃花暗
```

縮小比例、壓暗顏色、過渡秒數都在 `CharacterSpriteLayer` 元件上調。

##### 同一個位置站多人（自動）

同一個 `at:` 可以站好幾個人，程式會自動排前後：

| 誰 | 表現 |
|---|---|
| 說話者 | **被推到最前**，原本的大小與亮度 |
| 同位置的其他人 | 往後擠：**更小、更暗，並稍微偏移**讓他露出來 |
| 越後面的 | 每往後一層再縮一次、再暗一次 |

```ink
@sprite:momoka at:left
@sprite:saki at:left        ← 兩個人都站左邊

#speaker:momoka
妳今天太安靜了。            ← 桃花在前，紗季被擠到後面（更小更暗）

#speaker:saki
......有嗎。                ← 換紗季擠到前面
```

同位置的排序：**說話者永遠第一，其餘照出場順序**。
每層的縮放倍率、壓暗倍率、偏移量在 `CharacterSpriteLayer` 的「同位置前後」調。

#### `@dizzy` 暈眩

畫面波紋扭曲、整體來回旋轉、色散、邊緣壓黑，全部隨時間流動。

```ink
@dizzy:on                        開始暈（預設強度）
@dizzy:on strength:0.8 dur:2     花 2 秒漸強到 0.8
@dizzy:off                       漸退回正常
@dizzy:off dur:3                 花 3 秒慢慢退
@dizzy:pulse strength:1 dur:1.2  暈一下就恢復
@dizzy:on strength:0.4 wait      漸強跑完才顯示下一句
```

| 參數 | 可填 | 預設 | 說明 |
|---|---|---|---|
| **值** | `on` / `off` / `pulse` | 必填 | `pulse` 是衝到指定強度再退回 0 |
| `strength:` | 0～1 | 0.5 | 一個數值同時控扭曲、旋轉、色散與壓黑 |
| `dur:` | 秒數 | 1 | 漸強／漸退／一次脈動的總時間 |
| `wait` | 旗標 | 不加＝不等 | `on`／`off` 專用，要等漸變跑完才往下 |
| `nowait` | 旗標 | 不加＝會等 | `pulse` 專用，不等它跑完 |

⚠️ **等待規則跟其他指令相反。** `on` 和 `off` 是**持續狀態**，預設**不會**擋住對話——因為角色通常要邊暈邊講話。只有一次性的 `pulse` 預設會等。

強度 1 時的扭曲量、波紋密度、流動速度、旋轉角度、色散、壓黑，全都在場景 Volume Profile 的「暈眩 Dizzy」override 上調，劇本只給 `strength`。

```ink
#speaker:saki
站起來的瞬間，視線突然歪掉。
@dizzy:on strength:0.3 dur:1.5
扶著牆才沒有倒下去。
房間在慢慢地轉。
@dizzy:on strength:0.8 dur:3
......
@dizzy:off dur:2
過了一會兒，才慢慢看清楚地板的紋路。
```

#### `@clear` 清空對話框

```ink
@clear          清空對話文字，並隱藏名字欄
@clear:text     只清文字，名字欄保留
@clear:name     只隱藏名字欄，文字保留
```

| 參數 | 可填 | 預設 | 說明 |
|---|---|---|---|
| **值** | 空白 / `text` / `name` | 空白＝兩個都清 | 要清哪一個 |

不清的話，上一句會一直留在對話框裡。轉場、特效字、黑畫面之前通常都要清：

```ink
轉身衝向房門，伸手抓向金屬門把——
@clear
@fade:out dur:0.2
@fx:滴滴滴滴 anim:rise
```

#### 標準轉場寫法

```ink
轉身衝向房門，伸手抓向金屬門把——
@clear                      ← 先清掉上一句
@fade:out dur:0.2           ← 畫面淡黑
@fx:滴滴滴滴 anim:rise       ← 在黑畫面裡響的鬧鐘

@bg:saki_room_morning       ← 畫面還是黑的，所以直接切就好
@fade:in dur:1              ← 淡回來
睜開眼。
```

**黑幕底下換背景用直接切，不要用 `in:fade`**——反正看不見，疊兩層淡入淡出只是浪費時間。

#### 之後會開的 `@` 指令（先寫沒關係，目前只印警告）

**若有需求可以新增**，跟程式端說一聲即可。

| 指令 | 用途 | 預計參數 |
|---|---|---|
| `@se:doorbell` | 一次性音效 | `vol:` |
| `@bgm:calm` | 背景音樂 | `stop`、`fade:` |
| `@ambient:rain` | 環境音 loop | `stop` |
| `@wait:0.8` | 停頓，不必點擊 | — |
| `@card:tarot_01` | 圖卡 | `at:` `in:` `out:` |
| `@ui:off` | 隱藏／顯示整個對話框 | — |
| `@shake:0.5` | 畫面震動（一次性） | `dur:` |
| `@flash:white` | 瞬間閃白／閃紅 | `dur:` |
| `@minigame:service` | 進小遊戲，結果寫回 ink 變數 | — |

### 4-2. `#` tag 一覽

⚠️ 再強調一次：**tag 綁的是「下一句文字」，後面沒有文字就完全不執行。**

#### `#speaker` 說話者

```ink
#speaker:yuan               名字欄顯示「淵」
#speaker:ling as:？？？       顯示「？？？」（身分未明時）
#speaker:                   隱藏名字欄（旁白）
```

| 參數 | 可填 | 預設 | 說明 |
|---|---|---|---|
| **值** | 角色 key | 空白＝旁白 | key 登記在 `Assets/SO/DialogDatabase.asset` |
| `as:` | 任意文字 | 不覆蓋 | 蓋掉資料表裡的顯示名，用在還沒表明身分的角色 |

- **說話者會沿用到下一個 `#speaker:` 為止**，同一人連講三句只要寫一次
- **換成旁白一定要寫空的 `#speaker:`**，否則名字欄還掛著上一個人
- 找不到 key 會印警告，並**直接顯示 key 本身**（方便發現漏填）

詳見第 3 節。

#### 之後會開的 `#` tag

| tag | 用途 |
|---|---|
| `#speed:0.1` | 這句的打字速度（心跳加速、緩慢回想） |
| `#instant` | 這句不逐字，整句直接出現 |
| `#voice:xxx` | 這句的語音檔 |
| `#style:inner` | 這句的呈現樣式（心聲、回想） |

### 4-3. 共用參數

同一個參數在不同指令裡意思一致。

| 參數 | 意思 | 目前用在 |
|---|---|---|
| `dur:` | 秒數 | `@bg`（整段）、`@fade`、`@fx`（每個字）、`@sprite`、`@dizzy` |
| `nowait` | 不等它跑完，下一行馬上接 | `@bg` `@fade` `@fx` `@sprite` `@dizzy:pulse` |
| `wait` | 反過來，要等它跑完 | `@dizzy:on` `@dizzy:off` |
| `strength:` | 效果強度 0～1 | `@dizzy` |
| `in:` | 進場方式 | `@bg` `@sprite`（`cut` / `fade`） |
| `color:` | 顏色（`black` `white` `red` `#RRGGBB`） | `@fade` |
| `anim:` | 動畫預設名稱 | `@fx` |
| `as:` | 覆蓋顯示文字 | `#speaker` |
| `out` | 退場 | `@sprite` |
| `face:` | 表情 | `@sprite` |
| `at:` | 位置（`left` `center` `right`…） | `@sprite` |
| `*` | 全部，例 `@sprite:* out` | `@sprite` |

### 4-4. 不要用演出指示做的事

改變**畫面與聲音**才用 `@` / `#`；改變**遊戲狀態**一律用 ink 本身的語法。

| 需求 | 用什麼 |
|---|---|
| 記錄玩家做過什麼 | `~ flag_met_ling = true` |
| 分支判斷 | `{條件: … }` |
| 跳段 | `->knot` |

混在一起之後很難查問題。

## 5. 命名規範

### 5-0. 通則

- **全小寫、英數與底線**（`snake_case`）。不用中文、不用連字號、不用空格
- **key 不帶類別前綴**：寫 `cafe_night`，不是 `bg_cafe_night`——類別由指令決定
- **檔名 = 前綴 + key**：`bg_cafe_night.png`。這樣在專案視窗打 `bg_` 就能撈出同類全部
- 想不到名字時，寧可長一點也不要縮寫。`saki_room_morning` 比 `skr_m` 好

### 5-1. 角色 key（`#speaker:` `@sprite:`）

用角色本名的羅馬拼音。

| key | 顯示名 | 設定文件裡的稱呼 | 備註 |
|---|---|---|---|
| `momoka` | 桃花 | **女A** | 暱稱「小桃」也用同一個 key |
| `saki` | 紗季 | **女B** | |
| （空白） | — | — | 旁白，寫 `#speaker:` |

⚠️ **淵與苓的 key 尚未確定**，等命名定了再補進這張表。

暱稱只影響**顯示名**，key 永遠是同一個。真的需要在畫面上顯示「小桃」時用 `#speaker:momoka as:小桃`。

**案件當事人**用案件編號開頭，避免跟主角群混在一起：`case01_woman`、`case01_boy`。

### 5-2. 背景 key（`@bg:`）

格式 `地點_時段` 或 `地點_狀態`。

```
cafe_day        cafe_night      cafe_closed
saki_room_dark  saki_room_morning
street_night    street_rain
```

固定字彙（不要自己發明同義詞）：

| 類型 | 可用 |
|---|---|
| 時段 | `morning` `day` `evening` `night` |
| 狀態 | `dark`（夢／異常）`rain` `closed` `empty` |

同一張圖只是調色不同（例如夢裡與清晨的同一個房間），仍然算**兩個 key**。

### 5-3. 立繪 key（`@sprite:`）

資料表裡的 key 是 `角色_表情`：`momoka_normal`、`saki_smile`。
劇本裡則是分開寫：`@sprite:momoka face:smile`，程式會自己組起來查表。

表情固定字彙：`normal` `smile` `sad` `angry` `surprised` `tired` `serious`
不夠用可以加，**但加了要寫進這張表**，不然會出現 `smile` / `happy` / `smile2` 三種寫法並存。

### 5-4. 音 key（`@se:` `@ambient:` `@bgm:`，尚未實作）

| 指令 | 用途 | 例 |
|---|---|---|
| `@se:` | 一次性音效 | `doorbell` `alarm` `cup_place` `door_open` |
| `@ambient:` | 循環環境音 | `clock_tick` `heartbeat` `rain` `city_night` |
| `@bgm:` | 背景音樂 | `calm` `tension` `sad` `daily` |

判準：**會自己停的用 `se`，要手動停的用 `ambient`。** 時鐘滴答、心跳都屬於 `ambient`。

### 5-5. 特效字動畫 key（`@fx` 的 `anim:`）

用**動作**命名，看名字就知道畫面在幹嘛：

```
rise      由大變小往上飛
pop       瞬間放大再縮回
shake     原地震動
drop      從上方掉下來
```

### 5-6. 圖卡 key（`@card:`，尚未實作）

格式 `類別_編號`，編號補零兩位：`tarot_01`、`menu_03`。

### 5-7. ink 變數

用前綴分類，一眼看得出用途與生命週期：

| 前綴 | 用途 | 例 |
|---|---|---|
| `flag_` | 一次性旗標 | `flag_met_ling` |
| `count_` | 計數 | `count_visit_cafe` |
| `rel_` | 好感度／關係值 | `rel_yuan` |
| `ch01_` | 只在該章用的暫時變數 | `ch01_asked_about_bell` |

## 6. 可用的進階語法

ink 會自己算完再吐純文字，所以全部支援。

```ink
VAR 客人數 = 0
~ 客人數 = 3                              // 賦值，行首用 ~

今天來了 {客人數} 個客人。                  // 內插
{客人數 > 0: 比昨天好一點。|一個都沒有。}    // 行內條件

{ 客人數 > 5:
    今天忙到沒空講話。
- else:
    閒得發慌。
}

{一次性內容|第二次會看到|之後都是這句}
&輪替一|輪替二|輪替三
```

也可以用：`=子段落`、tunnel（`->某段->`）、`== function 名稱() ==`、`LIST`。
